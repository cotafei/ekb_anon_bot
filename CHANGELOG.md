 # История изменений EKB Anonymous Bot
 
 Все значимые изменения проекта документируются в этом файле.
 
 Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
 и проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
 
 ## [1.1.2] - 2026-03-04
 
 ### ✨ Добавлено
 - Rate limiting: защита от спама (POST_COOLDOWN_SECONDS = 60)
 - Проверка размера медиа: контроль фото и видео (до 20MB)
 - SUPPORT_CONTACT: контакт поддержки вынесен в config (@C0taf31)
 - Логирование модераторов: ID модератора сохраняется в БД
 - Проверка самоприглашения: нельзя пригласить самого себя
 - Подпись к медиа: фото/видео без текста теперь отклоняются
 
 ### 🔧 Улучшено
 - Модерация: передача moderator_id в approve_post/reject_post
 - База данных: улучшена функция add_user_points с referrer_id
 - Просмотр поста: добавлена информация о модераторе в handle_view
 - Обработка ошибок: более детальное логирование в post_handler
 - Реферальная система: динамические значения из config
 
 ### 🐛 Исправлено
 - Исправлена двойная проверка бана в post_handler
 - Исправлен импорт stats_handler в main.py
 - Исправлена обработка пустых подписей к медиа
 - Улучшена проверка прав бота в канале
 
 ### 📦 Изменено
 - Версия обновлена до 1.1.2 во всех файлах
 - DAILY_BONUS вынесен в config
 - POST_COOLDOWN_SECONDS добавлен в config
 - Улучшена документация кода
 
 ## [1.1.1] - 2026-03-03
 
 ### 🐛 Исправлено
 - Исправлена ошибка с распаковкой полей в admin.py
 - Исправлена работа команд /skip и /moderate
 - Исправлена проблема с переменной post_id в блоке except
 - Исправлены битые символы в stop.sh
 
 ### 🔧 Добавлено
 - Скрипт миграции migrate_db.py для безопасного обновления БД
 - Скрипты update_from_github.sh и update_from_github.bat для автообновления
 - Защита от двойной модерации через _post_locks
 - Проверка прав доступа для всех команд
 
 ### 📦 Изменено
 - Обновлена структура проекта (src/, docker/, scripts/)
 - Улучшена обработка ошибок в админ-панели
 - Добавлены исчерпывающие комментарии к коду
 
 ## [1.1.0] - 2026-03-02
 
 ### ✨ Добавлено
 - Docker-поддержка: полная контейнеризация, docker-compose, volumes
 - FSM-модерация: машина состояний для пошагового отклонения постов
 - Система монет: заработок за активность и рефералов
 - Реферальная программа: 50 монет за друга, 25 за друга друга
 - Ежедневный бонус: +10 монет каждый день
 - Магазин привилегий: заглушка с 4 товарами
 - Автоматические бэкапы: скрипты для резервного копирования
 - Windows support: полная поддержка (run.bat, backup.bat, restore.bat)
 
 ### 🔧 Улучшено
 - Новая структура проекта с разделением на src/, docker/, scripts/
 - Улучшенная фильтрация контента (регулярные выражения)
 - Личная статистика пользователей (процент одобрения)
 - Глобальная статистика для админов
 
 ### 🐛 Исправлено
 - Исправлена проблема с одновременной модерацией одного поста
 - Исправлена утечка памяти при обработке команд
 - Улучшена обработка ошибок подключения к Telegram
 
 ## [1.0.0] - 2026-02-27
 
 ### 🎉 Первый релиз
 
 ### ✨ Добавлено
 - Базовая архитектура бота на aiogram 3.x
 - Отправка текстовых постов на модерацию
 - Поддержка фото и видео
 - Простая модерация с кнопками (одобрить/отклонить)
 - База данных SQLite для хранения постов и пользователей
 - Фильтрация контента (мат, ссылки, контакты)
 - Команды: /start, /help, /rules, /stats, /moderate
 
 ### 🔧 Инфраструктура
 - Конфигурация через .env файл
 - Логирование всех действий
 - Обработка ошибок и автоматическое переподключение
 - Поддержка Windows и Linux

 ## Как обновиться
 
 ### С 1.0.0 до 1.1.0
 ```bash
 cp -r data backups/data_1.0.0
 git pull origin main
 python src/migrate_db.py
 ./scripts/run.sh
 ```
 
 ### С 1.1.0 до 1.1.1
 ```bash
 ./scripts/update_from_github.sh
 ```
 
 ### С 1.1.1 до 1.1.2
 ```bash
 ./scripts/update_from_github.sh
 ```
