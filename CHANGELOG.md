# История изменений EKB Anonymous Bot

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
и проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.1] - 2026-03-03

### 🐛 Исправлено
- Исправлена ошибка с распаковкой полей в admin.py (9 полей вместо 8)
- Исправлена работа команд /skip и /moderate
- Исправлена проблема с переменной post_id в блоке except
- Исправлены битые символы в stop.sh

### 🔧 Добавлено
- Скрипт миграции migrate_db.py для безопасного обновления БД
- Скрипты update_from_github.sh и update_from_github.bat для автообновления
- Защита от двойной модерации через _post_locks
- Проверка прав доступа для всех команд

### 📦 Изменено
- Обновлена структура проекта (src/, docker/, scripts/)
- Улучшена обработка ошибок в админ-панели
- Добавлены исчерпывающие комментарии к коду

## [1.1.0] - 2026-03-02

### ✨ Добавлено
- **Docker-поддержка**: полная контейнеризация, docker-compose, volumes
- **FSM-модерация**: машина состояний для пошагового отклонения постов
- **Система монет**: заработок за активность и рефералов
- **Реферальная программа**: 50 монет за друга, 25 за друга друга
- **Ежедневный бонус**: +10 монет каждый день
- **Магазин привилегий**: заглушка с 4 товарами
- **Автоматические бэкапы**: скрипты для резервного копирования
- **Windows support**: полная поддержка (run.bat, backup.bat, restore.bat)

### 🔧 Улучшено
- Новая структура проекта с разделением на src/, docker/, scripts/
- Улучшенная фильтрация контента (регулярные выражения)
- Личная статистика пользователей (процент одобрения)
- Глобальная статистика для админов

### 🐛 Исправлено
- Исправлена проблема с одновременной модерацией одного поста
- Исправлена утечка памяти при обработке команд
- Улучшена обработка ошибок подключения к Telegram

## [1.0.0] - 2026-02-27

## Как обновиться

### С 1.0.0 до 1.1.0
```
# Сделайте бэкап
cp -r data backups/data_1.0.0

# Обновите файлы
git pull origin main

# Запустите миграцию БД
python src/migrate_db.py

# Запустите бота
./scripts/run.sh
```

### С 1.1.0 до 1.1.1
```
# Просто запустите скрипт обновления
./scripts/update_from_github.sh
```
