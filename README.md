## 📱 О проекте

**EKB Anonymous Bot** — это высоконагруженный Telegram-бот для анонимных публикаций в городском сообществе Екатеринбурга. Проект представляет собой полностью готовое решение с системой модерации, геймификацией и внутренней экономикой.

### 🎯 Для чего это?
- 🔐 **Анонимное общение** — пользователи делятся мыслями без страха быть узнанными
- 👮 **Контроль контента** — модераторы фильтруют нежелательные посты
- 💰 **Монетизация активности** — система поощрения активных пользователей
- 📊 **Аналитика** — полная статистика постов и пользователей

## 📦 Установка и запуск

### 🔧 Требования
- Python 3.9 или выше
- Telegram Bot Token (получить у @BotFather)
- Telegram канал для публикаций

### 🚀 Быстрый старт
```bash
# 1. Клонирование репозитория
git clone https://github.com/yourusername/ekb-anon-bot.git
cd ekb-anon-bot

# 2. Установка зависимостей
pip install aiogram python-dotenv

# 3. Настройка конфигурации
cp .env.example .env
# Отредактируйте .env файл (токен, канал, админы)

# 4. Запуск
python main.py
```

## 📝 Конфигурация (.env)
```env
# Токен бота (обязательно)
TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# ID канала (обязательно, формат: -1001234567890)
CHANNEL_ID=-1001234567890

# ID администраторов через запятую (обязательно)
ADMINS=123456789,987654321

# Путь к БД (опционально)
DB_PATH=anon_ekb.db
```

## 📁 Архитектура проекта
```
📦 ekb-anon-bot
├── 📄 main.py              # Точка входа, обработка ошибок, auto-reconnect
├── 📄 config.py            # Конфигурация с валидацией переменных
├── 📄 database.py          # Работа с БД (7 таблиц, транзакции)
├── 📄 handlers.py          # Обработчики пользовательских команд
├── 📄 admin.py             # Панель модератора (inline-клавиатуры)
├── 📄 features.py          # Реферальная система, бонусы, магазин
├── 📄 filters.py           # Фильтрация контента (regex, blacklist)
├── 📄 utils.py             # Публикация в канал, уведомления
├── 📄 .env.example         # Шаблон конфигурации
└── 📄 requirements.txt     # Зависимости проекта
```
